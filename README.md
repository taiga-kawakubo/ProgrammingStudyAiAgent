# ProgrammingAI

ProgrammingAIは、プログラミング初学者が「自分でコードを読む、考える、確認する、書く」力を育てるためのCodex用Projectフォルダです。

このフォルダをコピーしてCodexアプリで開くと、学習支援Agentとして使えます。
学習者が特別な準備や専門的な操作を覚える必要はありません。

## 使い始め方

1. `ProgrammingAI` フォルダをコピーする
2. Codexアプリで、コピーした `ProgrammingAI` フォルダをProjectとして開く
3. chatに `学習開始` と入力する
4. 分からないことを、そのまま質問する

最初の入力例:

```md
学習開始
```

質問例:

```md
Route、Controller、Bladeの流れが分かりません。
このファイルだけ見てください: resources/views/books/index.blade.php
```

## このProjectがしてくれること

- 質問を `feature`、`unit`、`assess`、`error` に分類する
- 回答の冒頭に、分類と分類理由を短く表示する
- 最初は考え方と確認順序を優先して説明する
- 必要な場合だけ、修正案やコード例を出す
- 回答の最後に、軽い理解確認を1つ出す
- 理解確認への返答や新しい質問への移行を、ログ化確認の判断材料にする
- 「内容をまとめてほしい」と言われたら、まずログ候補を作る
- 保存の許可を受けた内容だけ、学習ログとして保存する
- 保存しないと指定された場合は、軽量メモも残さない
- プログラミング学習の質問は、Learning Caseに日付ごとで保存する
- 途中の学習テーマが残っている場合は、次回入力時に短く知らせる
- 最近の学習傾向、復習、最初に意識する確認ポイントを出す
- 日付が変わった後の最初のプログラミング学習質問では、最近の学習傾向を出したうえで質問にも回答する
- 苦手傾向を、技術知識、構造理解、思考プロセスに分けて整理する

## 学習中の基本ルール

ProgrammingAIは、学習者が明示した範囲だけを見ます。

たとえば、次のように指定できます。

```md
このファイルだけ見てください: routes/web.php
```

範囲があいまいな場合、ProgrammingAIは先に確認します。

```md
「viewファイル」とありますが、次のどちらを見ればよいですか？
1. resources/views/books/index.blade.php
2. resources/views/layouts/app.blade.php
```

## 学習ログの保存

回答後や理解確認への返答後、復習価値がありそうなとき、ProgrammingAIがログ化を確認します。

```md
この内容を学習ログに残しますか？
```

学習者がログ化を選んだ場合、ログ候補を作ります。候補を作った後、保存してよいかを別に確認します。
ログ候補は、chatで修正内容を伝えるか、必要に応じてファイルを直接直せます。

修正が終わったら、chatで次のように伝えます。

```md
修正完了
```

保存を許可した場合だけ、確定学習ログが作られます。

「内容をまとめてほしい」と明示された場合は、その時点でログ候補を作ります。その後、保存の許可を確認します。

ログ化しない場合でも、プログラミング学習の質問はLearning Caseに状態更新として残ります。保存しないと明示された場合は、確定学習ログや軽量メモは残しません。

## 保存される場所

```md
learning-cases/
```

日付ごとの一次記録を保存します。保存内容は、質問全文、回答要点、学習根拠に絞ります。
途中の学習テーマは `inbox`、一区切りになった学習テーマは `outbox` のリンク集から探せます。

```md
learning-logs/
```

確定した学習ログを保存します。
ファイル名は `YYYY-MM-DD-NNN-日本語件名.md` を基本にします。

```md
notebook/
```

最近の学習傾向、復習、苦手傾向、学習者に関するMemoryを保存します。

### 保存先の注意

学習ログは、このProjectフォルダ内にだけ保存します。
Codex全体の補助メモリである `/Users/taiga/.codex/memories/` や `.codex/memories/` には保存しません。

`ログ化してください`、`保存してください` と伝えた場合でも、正式な保存先は次です。

```md
learning-logs/YYYY-MM-DD-NNN-日本語件名.md
```

Project外へ保存されそうな場合は、保存を止めて保存先を確認します。

## 困ったとき

最近の傾向を見たい場合:

```md
学習開始
```

日付が変わった後は、最初の `学習開始` または最初のプログラミング学習質問で、最近の学習傾向、復習、最初に意識する確認ポイントを表示します。
最初の入力が質問だった場合は、その学習前メモを表示したあと、同じ質問への回答も続けます。

今の学習内容をログ化したい場合:

```md
この内容をログ化したいです
```

前の学習内容に戻りたい場合:

```md
前の学習内容に戻りたいです
```

途中の学習テーマが残っている場合は、入力時に短いメモが表示されます。

## 保守者向け

開発者や保守者が構成や検証方法を確認する場合は、次を見てください。

```md
docs/MAINTAINER_GUIDE.md
docs/RequirementsDefinition.md
AGENTS.md
PROJECT_STRUCTURE.md
SMOKE_TEST.md
```

保守時は、まず要件定義で目的と課題意識を確認し、実際の動作ルールは `AGENTS.md` とSkill本文を確認します。
`.codex/internal/validation/ProgrammingAIAgent.rb` はAgent本体の実装ではなく、設定値と保存済み分類ラベルの整合性を確認する最小チェッカーです。
